# Summarize review sentiment by product category


A companion to Data-oriented Programming Paradigms (188.995). The original group project compared sentiment and subjectivity across categories of Amazon reviews, in addition to exploring aspects and ratings. The report used category medians to summarize sentiment scores.

The example computes those summaries on fictional scores. Counts are included so a category with fewer records does not look as well supported as a larger one. The scores are inputs, not model predictions or empirical findings.

    python3 demo.py
